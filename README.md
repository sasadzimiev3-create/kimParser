# kimparser

Слушает четыре темы в чатах аккаунта. Если в тексте есть ключ, оригинал уходит тем, кто подключился к боту.

Человек нажимает /start и вводит пароль. После верного пароля бот отвечает «Вы подключены!» и начинает присылать совпадения. До этого сообщения не приходят.

Темы:

- https://t.me/jetlagchat/44320
- https://t.me/jetlagchat/44329
- https://t.me/WorkProKino/196
- https://t.me/WorkProKino/131
- https://t.me/Kinopeople/264492 — группа принимает только заявку. После одобрения администратором тема подключается сама.

Ключ ищется внутри текста, без учёта регистра. Буква `ё` совпадает с `е`. Запятая, точка и другие знаки рядом со словом не мешают: `Оператор,` и `Оператор.` считаются совпадением. Правки сообщений и подписи к фото или видео не смотрятся.

Секреты лежат в `.env` на сервере и в git не попадают. Сессия входа тоже.

## Сервер

Код выкатывается только в `/opt/kimparser` на `31.76.53.4`. CoffeDzhim, nginx и izicrm этот выкат не трогает.

```bash
bash deploy/deploy.sh
```

Сервис `kimparser` перезапускается только если он уже запущен.
